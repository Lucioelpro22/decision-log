# Decision Log

Registro profesional y liviano para documentar decisiones técnicas con contexto, alternativas, impacto y revisión posterior.

## Uso local

Abrí `dist/index.html` en un navegador. La información se guarda en `localStorage` y puede exportarse como JSON.

## Funcionalidades

- Alta, edición y eliminación de decisiones.
- Estado, impacto, responsables, etiquetas y fecha de revisión.
- Alternativas consideradas y motivos de descarte.
- Vista de detalle y revisión posterior.
- Búsqueda y filtros.
- Exportación JSON.
- Importación de respaldos JSON con validación.
- Exportación del registro completo en Markdown.
- Indicadores de revisiones vencidas.
- Duplicado rápido de decisiones como nuevas propuestas.
- Tema visual persistente.
